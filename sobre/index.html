Sobre o Conexus

Um espaço independente para aproximar ideia e conhecimento.

O Conexus organiza leitura curta por matéria. Cada artigo apresenta uma ideia com clareza e indica um caminho para aprofundar o tema.

Princípio do projeto

  • Modularidade: cada página cresce sem refazer o site.
  • Autonomia: o site funciona sem biblioteca ou serviço externo.
  • Clareza: cada texto trata de uma ideia por vez.
  • Escrita no singular: cada texto usa substantivo no singular.

Consulte o código e o conteúdo no repositório do Conexus no GitHub.
